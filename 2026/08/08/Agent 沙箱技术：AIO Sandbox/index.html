Agent 沙箱技术：AIO Sandbox

官方文档地址：AIO Sandbox

摘要

  • 具有一定配置的Sandbox，适合用于需要共享文件等的session级任务

简介

云原生轻量级沙箱环境，整合了以下6大类工具：

  • 浏览器：支持可视化操作
  • 终端：WebSocket-based的网页终端，可执行Linux命令，预配置了Python、Node.js、Git
  • 共享的文件系统
  • VsCode Sever
  • MCP服务器

解决了以下痛点：

  • 通过统一文件系统，解决工具碎片化，协同效率低
  • 用容器化解决环境配置复杂
  • MCP兼容API，解决AI Agent需要重复造轮子

使用

引入agent_sandbox库，使用docker镜像部署后运行在端口，python程序创建Sandbox对象监听端口。

通过Sandbox对象进行操作：

浏览器

使用Playwright库的集成进行浏览器会话链接

并使用GUI操作进行交互

文件操作

MCP

浏览器工具

  • browser_navigate - 导航到 URL
  • browser_click - 点击元素
  • browser_type - 输入文本
  • browser_screenshot - 捕获截图
  • browser_extract - 提取页面内容

#文件工具

  • file_read - 读取文件内容
  • file_write - 写入文件
  • file_list - 列出目录内容
  • file_search - 搜索文件内容
  • file_replace - 替换文件中的文本

#终端工具

  • terminal_execute - 运行 Shell 命令
  • terminal_session - 管理终端会话
  • terminal_kill - 终止进程
  • sandbox_execute_bash - 运行 Bash 管道命令；支持 truncate 参数，默认截断超长输出，设为 false 时返回完整输出。更多细节见 Bash 管道。

#文档工具

  • markitdown_convert - 将文档转换为 Markdown
  • markitdown_extract - 从文档中提取内容
