PyNPut笔记

发表时间：2026-03-16

计算机基础 python

补充 ：该技术与PyAutoGUI技术关联较高，主要为监听特化。

该技术主要分两个模块mouse和keyboard，其下又各分控制与监听两部分。

一、鼠标操作

1.控制

概述： 鼠标按键在mouse.Button中，分为lift、right、middle和unknown，每个按键有name和value两个属性：name为按键名；value为上次点击位置的元组。进行鼠标操作前需要先生成Controller对象,应用该对象对鼠标进行操作。

  • loc=mouse.position：获取鼠标位置
  • mouse.position = (x, y)：改变鼠标位置
  • mouse.move(250, 250)：移动鼠标的相对位置
  • mouse.click(Button.right/left/middle,int)：点击鼠标指定键位int次
  • mouse.press(Button.right/left/middle)和mouse.release(Button.right/left/middle)：click函数的拆解，按下与松开
  • mouse.scroll(x,y)：滚动滚轮

2.监听

方式1： 构造on_move（移动到的坐标）,on_click（点击的坐标与点击的按键以及按下还是松开）,on_scroll（鼠标位置和滚动变换的距离）函数，然后构造监听器对象mouse.Listener,将构造的监听函数注入，使用with或start()方法启动,调用Listener.stop()或在回调方法中ruturn False结束。

方式2： 使用event进行监听

二、键盘操作

1.控制

概述： 与鼠标类似，先声明Controller()对象，然后通过对该对象的操作进行键盘操作。

keyboard.press(Key.button) keyboard.release(Key.button) keyboard.type('string') # 输入

2.控制

方式1： Listener，与鼠标监控大差不差，没有了对滚轮的监控，监听函数只有key参数（操作的按键）。

方式2： event方式，同样大差不差。
